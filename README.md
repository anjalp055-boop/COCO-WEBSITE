COCO Website
A modern and responsive website project built for COCO, designed with a clean interface and user-friendly experience.


 About the Project
COCO Website is a web development project created to provide an attractive and responsive online experience. The project focuses on a clean design, easy navigation, and a visually appealing layout.

Features
> Modern and clean UI
> Responsive design for mobile, tablet, and desktop
> Easy navigation
> Fast and lightweight website
> Attractive images and visual elements
> Interactive buttons and sections
> Cross-browser compatible

 Technologies Used
HTML5 – Website structure
CSS3 – Styling and responsive design
